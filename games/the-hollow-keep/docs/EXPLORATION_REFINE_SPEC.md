## 1. 사용자 결정 (2026-11-01, PR #11 미리보기 확인 후)

| 항목 | 결정 |
|---|---|
| "문"의 두 뜻 | **명확히 구분한다.** ① 들어가면 다른 곳으로 가는 **출입문**, ② 잠겨 있으면 지나갈 수 없는 **봉쇄물(장애물)**. 지금 구현의 문은 모두 ②인데 문짝 모양이라 ①처럼 보였다(성문 방 천장의 봉인을 처음에 무엇인지 몰랐음) |
| 여는 방식 | 봉쇄물마다 여는 방법이 있는 지금 구조는 **유지** |
| 조사 버튼 | **유지**. 출입문도 조사 또는 ↑로 들어간다 |
| 방 밀도 | **추가.** 사용자가 제시한 참고 화면의 화면 대비 캐릭터 비율·통로 비율이 레트로 픽셀아트에 맞음(캐릭터도 길도 잘 보임) |
| 막히지 않은 길 | 봉쇄물만 있는 것이 아니라 **막히지 않고 지나가는 길도 있어야 한다** |

참고 화면은 **막힘과 들어감이 한눈에 구분되는 원칙**과 **비율**만 참고한다. 생김새·배치·방 구성은 옮기지 않는다(DESIGN_DIRECTION §2).

## 2. 비율 분석 (Claude Code, 참고 화면은 눈으로 잰 근사치)

| | 참고 화면 | PR #11 구현 |
|---|---|---|
| 화면 가로:세로 | 약 1.9 : 1 | 1.78 : 1 (960×540) |
| 캐릭터 키 ÷ 화면 높이 | 약 0.13~0.14 | Ethan 0.126, Noah 0.119 |
| 통로 높이 ÷ 캐릭터 키 | 약 1.2~1.3배 | 방 전체가 한 공간(약 6~7배) |
| 한 화면의 층 | 4층 | 사실상 1층 |
| 빈칸 비율 | 약 0.5 | 0.84~0.85 (8방 모두) |

결론: **캐릭터 크기·화면 크기·1단계 조작 수치는 바꾸지 않는다.** 바꾸는 것은 방 안의 배치(통로 높이와 층)다.

통로 높이와 점프(1칸 = 30단위, Ethan 키 68·점프 80, Noah 키 64·점프 145):

| 통로 높이 | 그 안에서 가능한 것 |
|---|---|
| 3칸 (90) | 걷기. 점프하면 바로 천장(참고 화면에 가장 가까움) |
| 4칸 (120) | Ethan 짧은 점프 정도 |
| 5칸 (150) | Ethan 최대 점프 |
| 7칸 (210) | Noah 최대 점프 |

좁은 통로만 있으면 Noah의 높은 점프가 의미를 잃는다. 그래서 **기본 통로 4칸 + 꽉 끼는 3칸 구간 + 세로 통로·높은 공간**을 섞는다(§5).

## 3. 출입문 (`entrance`, 새 물건)

벽에 난 아치형 출입구. 앞에 서서 **↑ 또는 조사**를 누르면 짝이 되는 출입문으로 이동한다.

| 필드 | 뜻 |
|---|---|
| `id` | 구역 전체에서 유일 |
| `x, y, w?, h?` | 칸 단위. 기본 `w=2, h=3`(60×90단위, 캐릭터보다 조금 큼) |
| `to` | 짝 출입문의 `id`. 짝도 이 출입문을 `to`로 가리켜야 한다(양방향) |
| `lock?` | `{ "key": "<name>" }` — 그 열쇠가 있어야 열린다 |

규칙:

- **들어가는 조건:** 땅에 서 있고(`onGround`), 사다리에 매달려 있지 않고, 몸 가로 중심이 출입문 칸 안에 있고, 발 높이가 출입문 아래 끝과 같을 때(차이 2단위 이하) **↑ 또는 조사를 누른 순간**.
- **이동:** 짝 출입문의 방으로 바꾸고, 몸 가로 중심을 짝 출입문 가운데에, 발을 짝 출입문 아래 끝에 맞춘다. 속도 0, 땅에 선 상태. 날아가던 공격은 지운다. 그 방을 방문한 것으로 한다.
- **이벤트:** `{type:'enter', id, to, room}`(room = 도착한 방). 방이 바뀌면 이어서 `{type:'room', from, to, dir:'entrance'}`.
- **잠긴 출입문:** 열쇠가 없으면 `{type:'denied', id}`만 발생하고 이동하지 않는다. 열쇠가 있으면 1개를 쓰고 `{type:'unlock', id}` 후 **같은 입력으로 바로 들어간다.** 한 번 열리면 짝까지 계속 열려 있다.
- 출입문 앞에서 ↑를 눌러도 점프하지 않는다(점프는 점프 버튼). 사다리와 출입문은 겹치지 않게 배치한다(§6 검사).
- `getFlags()`에 `entered: { id: true }`(그 출입문으로 들어간 적 있음), `unlocked: { id: true }`(짝 둘 다 기록)를 추가한다.
- 출입문은 이웃하지 않은 방도 잇는다. 지도는 방 위치(`pos`)대로 그리며, 출입문 연결을 선으로 표시하는 것은 선택이다.

## 4. 봉쇄물 (`door` — 이름 그대로, 뜻과 그림을 바꿈)

데이터 `type`은 호환을 위해 `door` 그대로 쓰고, 문서·화면에서는 **봉쇄물**이라 부른다. 동작(닫혀 있으면 벽, 조건이 맞으면 열림)은 2단계 규격과 같다.

- **모양 규칙(자동 검사):** 봉쇄물은 **통로를 꽉 막는 모양**이어야 한다. 둘 중 하나:
  - 세로형: 바로 위 행과 바로 아래 행의 같은 열들이 모두 `#`(통로 높이에 딱 맞음)
  - 가로형: 바로 왼쪽 열과 바로 오른쪽 열의 같은 행들이 모두 `#`(세로 통로·구멍을 덮음)
  - 그리고 봉쇄물이 차지하는 칸은 격자에서 `#`가 아니어야 한다(빈 통로를 막는 것).
- **그림:** 문짝 모양은 쓰지 않는다. 쇠창살·내리닫이·격자 뚜껑·봉인 결계처럼 **"막혀 있다"**로 읽히게 한다.
  - `barrier-v`: 세로형 한 칸(60×60). 위아래로 이어 붙여 높이를 맞춘다.
  - `barrier-h`: 가로형 한 칸(60×60). 좌우로 이어 붙인다.
  - 여는 방법 표시(봉쇄물 가운데에 겹쳐 그림): `mark-key`(열쇠), `mark-lever`(레버 스위치), `mark-light`(빛 장치), `mark-target`(표적 처치). 글자 없이 기호로만.
  - 열린 봉쇄물은 그리지 않거나, 걷혀 올라간 짧은 흔적만 그린다(선택).
- 스위치는 `kind`를 반드시 적는다(`lever` 또는 `light`). 봉쇄물의 표시 기호를 정하는 데 쓴다.
- 부서지는 벽(`breakable`)은 **주변 벽과 거의 같게** 그리고 미세한 금만 둔다. 숨은 길이 바로 보이지 않게 하기 위함이다.

## 5. 방 밀도 (자동 검사, 격자 기준)

용어:
- **바닥칸:** `#` 또는 `-`인 칸. 그 위 칸이 `#`가 아니면 거기 설 수 있다.
- **설 곳:** 바닥칸 바로 위의 빈칸. **머리 공간**은 그 칸부터 위로 `#`가 나오기 전까지의 빈칸 수(`-`, `H`는 빈칸으로 센다). 캐릭터가 들어가려면 3칸 이상이어야 한다.
- **층:** 머리 공간 3칸 이상인 설 곳이 같은 행에 가로로 3칸 이상 이어진 바닥 행.

| 기준 | 값 |
|---|---|
| D1 빈칸 비율(`.`, `-`, `H` ÷ 576) | 방마다 0.70 이하, 구역 평균 0.60 이하 |
| D2 층 수 | 방의 75% 이상이 3층 이상 |
| D3 기본 통로 | 방마다 머리 공간 3~4칸인 설 곳이 가로 4칸 이상 이어진 구간 1개 이상 |
| D3 좁은 통로 | 구역 전체에 머리 공간 정확히 3칸인 구간(가로 4칸 이상) 2개 이상 |
| D3 높은 공간 | 구역 전체에 머리 공간 5칸 이상인 설 곳이 있는 방 3개 이상, 7칸 이상인 방 1개 이상 |
| D4 막히지 않은 길 | 봉쇄물·부서지는 벽·잠긴 출입문을 모두 닫힌 것으로 볼 때, 시작 위치에서 칸을 따라 갈 수 있는 방이 3개 이상 |
| D4 방 안 통과 | 열린 곳(가장자리의 이어진 열린 칸 묶음, 출입문)이 2개 이상인 방은, 봉쇄물·부서지는 벽을 닫은 채로도 그중 2개가 방 안에서 이어져 있다 |
| D5 숨은 곳 | 부서지는 벽을 부숴야만 칸을 따라 닿는 물건(열쇠·스위치·출입문·표적)이 1개 이상 |
| D6 Noah 높은 레버 | Noah 전용 레버마다: 가로 5칸 이내의 어떤 설 곳(사다리 꼭대기 포함)에서도 Ethan이 서서 뛴 몸 범위(바닥 − 148 ~ 바닥)가 레버 칸과 겹치지 않고, 1칸 이내의 설 곳 하나 이상에서 Noah의 몸 범위(바닥 − 209 ~ 바닥)가 레버 칸과 4단위 이상 겹친다. 레버 좌우 1칸 열에는 레버 행+3 위쪽으로 사다리가 없다 |

- D4·D5는 칸을 4방향으로 따라가는 **근사**다(점프 높이는 따지지 않는다). 실제로 갈 수 있는지는 완주 기록 재생이 확인한다.
- D6는 높이만으로 "Noah만 닿는 곳"이 되게 하는 기준이다. `hero:"noah"` 제한도 그대로 둔다(이중 장치).
- 수치는 시범 기준이다. 사용자가 해 보고 답답하거나 비어 보이면 조정한다.

## 6. 시범 구역 요구사항 (2단계 §7에 추가·변경)

2단계 §7의 요구사항(8~12방, 가로·세로 연결, 사다리, 한쪽 발판, 봉쇄물 3종, 전용 장치 2종, 부서지는 벽, 되돌아가기, 지름길, 완주 기록)은 유지하고 다음을 더한다.

- 출입문 짝 **2쌍 이상**. 그중 1쌍 이상은 **이웃하지 않은 방**(위치 차이 2 이상)을 잇는다. 잠긴 출입문 1개 이상.
- 출입문 배치: 칸이 방 안이고 `#`가 아니며, 아래 행이 모두 바닥칸(`#` 또는 `-`), 출입문 칸에 사다리(`H`)·스위치·열쇠가 겹치지 않는다. 짝이 서로를 가리킨다.
- 봉쇄물은 모두 §4 모양 규칙을 지킨다.
- §5 밀도 기준을 모두 지킨다.
- 완주 기록은 2단계 조건에 더해 **출입문 짝마다 한 번 이상 지나가고**, 잠긴 출입문을 모두 연다.
- 방 배치·퍼즐은 PR #11 구역을 고쳐도 되고 새로 짜도 된다. 1단계 조작 수치와 캐릭터 크기는 바꾸지 않는다.

## 7. 그림 (ART_DIRECTION 규칙: scale 2, 64색, 투명도 0/255, 원래 해상도, 경로 A)

`objects` 필수 이름(2단계 목록을 바꿈):

| 이름 | 내용 |
|---|---|
| `barrier-v`, `barrier-h` | 봉쇄물 한 칸(이어 붙임) |
| `mark-key`, `mark-lever`, `mark-light`, `mark-target` | 여는 방법 기호 |
| `entrance` | 출입문 120×180(2×3칸), 안쪽은 어둡게 — 배경 쪽으로 들어가는 곳으로 보임 |
| `entrance-locked` | 잠긴 출입문(같은 크기) |
| `lever-off`, `lever-on`, `light-off`, `light-on`, `key`, `breakable` | 2단계와 같음 |

`door-closed`, `door-open`, `locked-door`는 더 이상 필수가 아니다(지워도 됨).
