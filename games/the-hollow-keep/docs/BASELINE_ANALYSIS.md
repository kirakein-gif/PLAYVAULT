## 2. 구조상 문제 (새 기반에서 바꿀 점)

1. **로직과 화면이 분리되어 있지 않음** — 물리·전투 상태가 `document`, 캔버스, 오디오 호출과 같은 함수 안에 섞여 있어 Node에서 따로 실행·검증할 수 없습니다.
2. **가변 시간 간격** — `frame()`이 `dt=(t-last)/16.67`(최대 2.2)로 프레임 시간에 따라 이동량을 바꿉니다. 화면 주사율·끊김에 따라 점프 높이와 판정이 미세하게 달라지고, 같은 입력을 재현할 수 없습니다.
3. **입력이 이벤트 핸들러에서 바로 동작을 실행** — `keydown`에서 `doJump()`·`doAttack()`을 직접 호출합니다. 틱 단위 입력 기록·재생이 불가능합니다.
4. **조작 수치가 코드 곳곳에 분산** — 주인공 수치는 `HEROES`에 있지만 공격 사거리·피해·경직·넉백은 `doAttack()` 안의 배열 리터럴에 있습니다.

## 4. 유지할 가치가 있는 것

- 두 주인공의 수치 차이(무거운 원거리 / 가볍고 빠른 근접)는 이미 플레이 감각의 출발점이 됩니다.
- 코요테 타임·점프 버퍼·짧은 점프는 이미 구현되어 있어, 새 기반에서도 같은 개념을 설정값으로 유지합니다.
- 고딕 타이틀 키아트(`assets/*.webp`)와 `art.js`의 배경 그림은 새 기반의 임시 그래픽으로 읽어 쓸 수 있습니다.
- 방 이름·환경 문장(예: "둘을 함께 들여보내지 마라.")은 세계관 자료로 보존합니다.

## 5. 마성전설2 감각과 비교한 관찰

- 현재 방은 좌우 출구만 있는 한 화면 단위입니다(`ROOMS`의 `L/R`). 위아래 연결(사다리·수직 통로)은 없습니다.
- 현재 Ethan의 룬탄은 화면 끝까지 날아가는 장거리 사격입니다. 근접 무기 중심의 촘촘한 탐험 감각과 맞을지는 플레이로 확인이 필요합니다(사용자 판단 사항).
