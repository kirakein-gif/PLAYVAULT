# v0.10 정지 포즈 이미지 제작 기록

- 제작: 2026-10-19, 내장 image_gen. 사용자 승인 예시 및 이 프로젝트의 기존 캐릭터를 기준으로 제작.
- `enemy-stills.png`, `player-stills.png`: 각각 1536×1024 RGBA. 3열×2행, 512×512 셀.
- 셀 순서: 망치 잡기 / 들기 / 내려치기 / 냄비 잡기 / 착용 / 대기.
- 인물·팔·손·들고 있는 도구가 통합된 완성 포즈. 몸 파츠나 팔을 독립 변형하지 않음.
- 생성 후 image_gen으로 배경 투명화. 최종 반환 PNG 픽셀을 재가공하지 않고 저장. 투명도는 알파 채널 표본으로 확인. `art.js`는 인접 셀 누출을 막는 샘플링 여백만 적용.
- 테이블 도구는 Canvas 그림이며 1.25배로 확대. 들고 있는 도구는 위 이미지 안에 포함됨.
- 외부 게임의 소스/아트/음원은 사용하지 않음. 원근·손잡이 위치와 프레임별 비례는 후속 미술 QA 대상.
