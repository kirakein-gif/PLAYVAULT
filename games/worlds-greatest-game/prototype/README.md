# 세계 최고의 게임 · 액션 프로토타입 v0.2

## 실행

`prototype/index.html`을 Windows Chrome 또는 Edge에서 엽니다. 설치·빌드·서버·인터넷 연결이 필요 없습니다. 파일 실행은 실제 Chrome에서 검증했습니다. 기존 `../index.html`은 v0.1 원본입니다.

## 한 판의 흐름

1. 가위·바위·보 버튼 또는 1/2/3으로 패를 고릅니다. 두 손이 함께 공개됩니다. 결과 안내는 없습니다.
2. 손 공개 후 자신의 판단으로 테이블 도구의 원형 손잡이 영역을 누릅니다. 이겼으면 망치, 졌으면 냄비, 비겼으면 기다립니다.
3. 망치는 **누른 채** 들어 올려 머리 부분이 상대 얼굴을 빠르게 통과하도록 휘두릅니다. 최소 이동량 105, 속도 460 논리 픽셀/초와 충돌·방향을 검사합니다. 클릭만 하거나 천천히 대면 공격되지 않습니다. 상대는 약 2.25초 뒤 냄비로 막습니다.
4. 냄비는 오른쪽 테두리를 **누른 채** 왼쪽 아래 내 머리 위로 가져갑니다. 냄비 중앙이 내 머리 윗부분에서 43 논리 픽셀 안에 130ms 머물면 착용합니다. 상대 타격까지 계속 잡으세요. 놓거나 머리에서 벗어나면 방어가 풀립니다. 상대는 약 2.1초 뒤 공격합니다.
5. 판정 뒤 `다음 판`을 누릅니다. 명중은 도전자 +1, 피격·파울은 최주임 +1. 방어·상대 방어·빗나감·무승부는 점수 없이 재경기. 먼저 3점이면 경기 종료입니다.

조기 도구 잡기, 잘못된 도구, 무승부 중 도구 사용은 사후 파울입니다. Esc, 창 초점 상실, 화면 이탈, 포인터 취소는 잡기를 해제합니다. 망치를 놓으면 헛스윙이며 냄비를 놓으면 방어가 풀립니다. 경기 재시작은 언제든 가능합니다. 효과음과 화면 흔들림은 별도로 끌 수 있습니다.

## 구조와 조정

- `config.js`: 경기 시간, 충돌/착용, IK 길이, 머리/손잡이 위치와 점수 기준.
- `engine.js`: DOM 없이 실행 가능한 상태·규칙·포인터 소유권·연속 충돌·IK 계산.
- `app.js`: Pointer Events, capture/해제, 논리 좌표 변환, 상태 UI, 오디오 이벤트.
- `render.js`: 3/4 상대/어깨너머 플레이어, 양측 손, 절차적 팔, 도구, 반동·표정·궤적·임팩트.
- `audio.js`: Web Audio 합성 효과음, 최대 12음, 음소거.

상태는 `select → reveal → react → resolve → select/end`. UI는 내부 RPS 결과를 읽어 사전 승패나 정답 도구를 안내하지 않습니다. 상대의 준비 동작은 경기 행동으로 보입니다.

## 검증 재현

저장소 루트에서:

```powershell
node games/worlds-greatest-game/prototype/tests/engine.cjs
node games/worlds-greatest-game/prototype/tests/browser.cjs
```

첫 검사는 Node만 필요합니다. 두 번째는 개발 검증용 Playwright 패키지와 설치된 Google Chrome이 필요합니다(`channel: chrome`, headless). 게임 자체에는 이 패키지가 필요하지 않습니다. `NODE_PATH`로 기존 Playwright 설치를 지정해도 됩니다. 두 번째 인자로 스크린샷 저장 폴더를 지정할 수 있습니다. 테스트는 브라우저 안에서만 난수를 고정하며 일반 게임에는 디버그 정답 UI나 고정 패가 없습니다.

검증 결과(2026-10-19): 규칙 13개 시나리오, 실제 Chrome 브라우저 15개 검사 통과. 1440px 및 960px에서 실제 마우스 스윙을 확인했고 1280px/DPR 2 렌더링을 확인했습니다. 화면 캡처에서 팔-손잡이 연결 및 냄비 착용 레이어를 검수했습니다. 브라우저 테스트는 클릭·드래그·해제·취소·화면 이탈·초점 상실·음소거/흔들림 설정을 포함합니다. `git diff --check` 통과.

## 현재 한계

도형으로 만든 성인 캐릭터 블로킹과 2본 IK입니다. 최종 극화체 아트·세밀한 손가락 리깅·얼굴 연기는 미완료이며 팔 길이와 자세도 후속 아트에 맞춰 조정해야 합니다. 효과음은 이 코드에서 만든 합성음으로 제3자 미디어를 사용하지 않았습니다. 자동화에서 음소거 및 오디오 코드 경로를 확인했지만 실제 스피커 청취 평가는 하지 않았습니다. 수동으로 느끼는 손맛, 낯선 사용자의 패 인지 속도, 장시간 플레이, 다른 브라우저 및 네이티브 Windows/Steam 배포는 별도 검증이 필요합니다. 터치 최적화·보스 확장·정식 오프닝은 이번 범위에 없습니다.
