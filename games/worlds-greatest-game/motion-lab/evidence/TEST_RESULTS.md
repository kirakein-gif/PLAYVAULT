명령은 [전용 README](../README.md)의 재현 검사를 참고합니다. Playwright1.56.1 + 설치된 Chrome, FFmpeg는 녹화 전용 작업 도구입니다. UI는 난수 패를 실제 사용하는 상태이며 검사에서만 난수를 바위로 고정합니다. 상태/도구 위치/승패를 주입하는 API는 없습니다.

실제 프레임 간격은 성능 측정에서 잘라내지 않습니다. 물리 적분의 최대 dt 제한과 성능 기록을 구분합니다. 위 측정은 이 Windows 실행 환경의 결과이며 다른 PC/GPU의 60fps를 보증하지 않습니다.

## 미실행·한계

- 독립 교차 검토, 사용자의 실물 마우스 손맛, 장시간 조작, 타 GPU/브라우저·태블릿·Windows 게임 빌드·Steam.
- 근골격·피부/근육·몸체 관통 방지. 팔·도구가 몸체를 통과하는 자세가 있을 수 있습니다. 현재는 3D 도형으로 관절 동작을 관찰하는 실험실입니다.
- 마우스 조작은 3D 평면과 팔 도달 범위의 영향을 받습니다. 자유 회전 카메라는 없습니다.
- 냄비 손잡이는 실험실에서 앞쪽으로 연장한 도형입니다. 실제 냄비 비례/그립·어깨 너머/두 사람 촬영 기준으로 추가 조정이 필요합니다.
- 상대 공격 스크립트 끝은 공개 후1.05초이며, 3D 충돌 구의 첫 접촉은 약1.01초입니다. 볼륨의 경계에 닿는 시점과 망치 중심이 끝점에 도착하는 시각은 다릅니다.

초기 환경 실패(DNS/loopback 차단·녹화용FFmpeg미설치)는 허용 실행과 작업 도구 설치 후 해결했으며 위 결과는 수정 후 최종 소스의 재실행입니다. 과거 prototype55개 검사를 이번에 실행한 결과가 아닙니다. **검사 통과를 손맛 완성으로 해석하지 않습니다.**
