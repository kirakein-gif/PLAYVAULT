# 세계 최고의 게임 · Motion Lab 0.2 / 수정 01-1

[PR #33](https://github.com/kirakein-gif/PLAYVAULT/pull/33)의 [Claude Code 리뷰](https://github.com/kirakein-gif/PLAYVAULT/pull/33#pullrequestreview-5794752764)를 반영했습니다. 기준 구현 `1b7d414`, 동작/카운트 기준은 원격 `ccr-a50ca9fd-k3ai31` `80cf145`의 [MOTION_REFERENCE](https://github.com/kirakein-gif/PLAYVAULT/blob/80cf145/games/worlds-greatest-game/docs/MOTION_REFERENCE.md)입니다. 원본 v0.1·prototype0.13과 별도이며 손맛은 사용자 판단 대기입니다.

## 실행

저장소 루트에서 Node.js로:

```sh
node games/worlds-greatest-game/motion-lab/tests/serve.cjs
```

`http://127.0.0.1:8080/games/worlds-greatest-game/motion-lab/`를 엽니다. 폴더만 압축으로 받았다면 그 안에서 `node start.cjs` → `http://127.0.0.1:8080/`. 빌드·npm 설치·외부 요청은 필요 없습니다. ES module을 쓰므로 file:// 더블클릭 대신 HTTP로 엽니다.

## 직접 조작

1. **한 판 시작**. 화면 중앙에 `2 가위 → 1 바위 → 0 보`가 나옵니다. 2·1에서 흔들고 0에서 내기 동작을 시작합니다.
2. **0 전까지 매 판 새로** `1/2/3` 키 또는 버튼으로 패를 고릅니다. 0 전에는 바꿀 수 있고 마지막 선택이 나갑니다. 0까지 없거나 0 이후 선택/변경을 시도하면 **파울: 늦은 손**입니다. 이전 판 선택은 이어지지 않습니다.
3. 양쪽 손을 보고 판단합니다. 승패는 판정 전에 알려주지 않습니다. 가위는 엄지+검지입니다. 손 모양은 0 이후 .22초 내기 동작의 마지막 .1초에만 공개합니다.
4. 망치는 손잡이를 누르고 점선 안내의 **장전 → 펴기 → 정수리**를 따라 움직입니다. 장전점에 도달해 실제 팔이 굽혀지면 다음 구간을 움직일 수 있습니다. 냄비는 손잡이를 누르고 **머리 위** 안내점까지 올려 유지합니다.
5. 결과 후 다시 시작합니다. 마우스를 놓으면 해제되며 냄비 방어도 풀립니다. 망치를 놓고 끝내면 빗나감입니다. 클릭한 채 멈춰 있으면 자동으로 공격/방어하지 않습니다.

관찰 패널에서 카메라3개·관절/뼈·0.25배속·상대 큰 반대 손/한 손·두 손 냄비를 고릅니다. 동작 설정은 **한 박자 .25~.9초(기본 .45)**, **속도 기반 손목 스냅 최대0~35°(기본±8)**입니다. 박자는 판 사이에 바꿉니다. 스냅은 실제 손목 가동 범위 안에서 제한됩니다. `Esc`·포커스 상실·포인터 취소·크기/카메라 변경은 안전 해제합니다.

## 바뀐 입력 방식

- 테이블 면과 상대 정수리 깊이 면을 전환하던 분기를 제거했습니다. 카메라가 투영한 안내 궤적에서 커서 이동을 접선 방향 진행량과 좌우 편차로 나눕니다. **시간이 아닌 마우스 이동**이 진행도를 바꾸고, 되돌리면 팔도 돌아갑니다.
- 픽업 자세에서 장전77°/92° → 최고165°/108° → 끝165°/95°의 관절 방향·팔꿈치 굽힘·쇄골/척추를 연속 보간합니다. 장전 자세를 실제로 통과해야 다음 구간이 열립니다. 커서를 멈추면 스프링이 현재 목표에 정착할 뿐 다음 단계로 가지 않습니다.
- 매 입력을 최대1px 길이로 나누고, 보간한 **요청 손 목표**의 3D 이동이 `C.input.maxTargetMetersPerPixel`(기본 **.006m/px**)를 넘지 않도록 제한합니다. 큰 이벤트·coalesced events·경로 모서리·되돌리기에도 같은 제한이 적용됩니다. 관절/입력 위반 수를 표시합니다.
- 이전의 상대 머리 바로 위로 올렸다 수직으로 내리는 입력만으로는 새 경로 검사에서 `miss`가 됩니다. 모든 허용 팔 자세가 장전·짧은 호 경로 안에 있으므로 **상대 머리 위에서 팔을 수직으로 뻗어 내려찍는 자세 자체가 나오지 않습니다**. 별도의 명중 차단 규칙을 덧붙이지 않았습니다.
- 냄비는 관절 방향/굽힘량을 보간해55° 아래로 더 접히는 구간을 없앴습니다. 한 손 끝 자세55°/75°·목18°를 플레이어와 상대에 사용합니다.
- 안내점은 조작 경로입니다. 원근과 최소 조작 구간 길이 때문에 커서가 매 순간 손잡이나 도구 중심과 정확히 겹치는 방식은 아닙니다. 접선 밖 이동은 제한된 좌우 조준 편차를 줍니다. 조작감·편차 폭은 사용자 피드백으로 더 조정해야 합니다.

카메라0은 플레이어 오른쪽 어깨 바로 뒤/바깥의 `(-.45,1.90,.96)`, 바라보는 점 `(0,1.36,-.49)`, 시야각70°입니다. 내 정수리보다 **뒤 .47m·위 .33m**, 어깨 바깥 .27m로 옮겼습니다. 뒤통수/어깨/오른팔은 오른쪽 전경에, 상대 얼굴과 손은 크게 보입니다. 검증 궤적의 공개·장전·최고점·충돌·냄비 순간에 상대 머리/손의 화면 좌표와 실제 전경 가림을 함께 검사합니다.

## 물리·촬영 기준

3D 고정 길이 골반→척추2→목/머리, 쇄골→위팔→아래팔→손/5개3마디 손가락입니다. 2마디 IK·pole·쇄골 상승·척추 기울기와 관절 범위를 유지합니다. 팔꿈치0~145° 제한은 **굽힘량**, 영상의165°는 굽힘15°입니다. 디버그에 안쪽 각도/굽힘량을 함께 표시합니다.

| 동작 | 촬영 기준 | 구현 기본값 |
| --- | --- | --- |
| 작게 흔들기 | 주기 .45~.50초, 안쪽50~75°, 위팔60~65° | .45초, 50~75°/62.5° |
| 내기 | .20~.25초, 안쪽약80° | .22초, 80°/62.5°, 마지막.1초 공개 |
| 크게 내기 | 120~140°/50~60° | 130°/55°, 반대 손·척추12°/회전10° |
| 망치 | .65~.80초, 장전70~85°, 최고약165°/105°, 끝10~15° 하강 | 상대 .73초, 플레이어 시간은 입력에 따름; 장전77°/92° → 최고165°/108° → 경로 끝165°/95° |
| 냄비 한 손 | .27~.30초, 55°/70~78°·고개 숙임 | 상대 .285초, 직접 입력 끝55°/75°·목18° |
| 냄비 두 손 | .33~.40초, 65~90°/80~120° | 상대 .365초, 양팔65°/100° |
| 냄비 내려놓기 | .30~.35초 | 상대 .325초 |

손은 임계 감쇠(90% 약60ms)로 목표를 따라가고, 도구 위치는 손 소켓과 같습니다. 실제로 손이 도달한 뒤 .1초에 손가락이 감싸며 회전만25ms 지연합니다. 판정은 기존 `Strike`/`Equip`을 유지합니다: 표시하는 도구의 3D swept sphere·정수리/속도/이동량/하강 방향/단발, 냄비 위치·법선·70ms 유지/이탈. 최초 체적 접촉은 중심이 끝점에 도달하기 전(직접 검사에서 위팔 약98°)입니다.

상대 공격 끝점은 공개 후.32+.73=1.05초, 방어는1.10초 근처입니다. 실제3D 충돌이 성립해야 결과가 나옵니다. 점수·에너지·트릭·보스는 추가하지 않았습니다. 목·머리 관절 반동과65ms hitstop은 유지하며 이전 판의 hitstop을 새 카운트로 넘기지 않습니다.

Three.js **0.180.0** 두 모듈을 로컬에 내장했습니다. [MIT 라이선스/출처](vendor/README.md), 이미지·폰트·CDN 없음. 스킨 메시나 인체 근골격 모델은 아닙니다.

## 검사·재현

```sh
node games/worlds-greatest-game/motion-lab/tests/unit.mjs
node games/worlds-greatest-game/motion-lab/tests/browser.cjs
```

Playwright1.56.1 설치가 필요합니다. 표준 모듈 경로에 없으면 `WGG_PLAYWRIGHT_PATH`로 지정합니다. 브라우저 선택:

- 기본은 설치된 Chrome을 시도하고 없으면 설치된 Playwright Chromium으로 대체합니다.
- `WGG_BROWSER_CHANNEL=chromium`: Chrome 채널을 사용하지 않습니다.
- `WGG_BROWSER_EXECUTABLE=/설치된/Chromium/실행파일`: 실행 파일을 직접 지정합니다.
- `PLAYWRIGHT_BROWSERS_PATH`: Playwright 브라우저 설치 폴더. `WGG_SOFTWARE_GL=1`로 SwiftShader 소프트웨어 렌더링을 시험합니다.
- `WGG_VIDEO=1`: 직접 명중·방어 앞 두 시나리오를 프레임별 실제 속도로 녹화합니다.

`page.clock`을 페이지 실행 전 설치·정지하고, `runFor`로만 시간을 전진시킵니다. rAF를30/60fps 두 조건으로 실행해 같은 마우스·키 입력과 결과를 검사합니다. GPU 처리/스크린샷/도구 왕복 시간이 경기 시간을 소모하지 않습니다. 실제 창 크기 이벤트 전달만 경기 시계를 멈춘 채 기다립니다. 검사에서는 난수만 바위로 고정합니다. `window.motionLab`은 상태/투영 조회 전용이며 결과나 손 위치를 주입하지 않습니다.

이번 결과·새 캡처·녹화는 [수정01-1 검증](evidence/revision-01-1/TEST_RESULTS.md)을 보세요. 기존 evidence/의0.1 검증/영상은 당시 기록입니다. 고정 시계의30/60fps를 실제 GPU 성능 측정으로 해석하지 않습니다.

## 한계
