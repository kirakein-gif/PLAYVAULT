# 세계 최고의 게임 · Motion Lab 0.1

촬영 기준 v0.2를 비교하는 그림 없는 3D 관절 실험실입니다. 원본 v0.1과 미병합 prototype 0.13과 별도입니다. 손맛은 사용자 직접 판단 대기입니다.

## 실행

Node.js가 있으면 저장소 루트에서:

```sh
node games/worlds-greatest-game/motion-lab/tests/serve.cjs
```

브라우저에서 `http://127.0.0.1:8080/games/worlds-greatest-game/motion-lab/`를 엽니다. ZIP으로 이 폴더만 받은 경우에는 압축을 풀고 폴더 안에서 `node start.cjs`를 실행한 뒤 `http://127.0.0.1:8080/`를 엽니다. HTML을 file://로 더블클릭하면 브라우저의 ES module 보안 제한이 적용되므로 HTTP 서버가 필요합니다. 빌드·npm 설치·외부 네트워크 요청은 필요 없습니다.

## 조작

1. 한 판 시작. 두 번 작게 흔든 뒤 세 번째 박자에 공개합니다. 카운트 중 `1 가위 / 2 바위 / 3 보` 또는 버튼으로 예약합니다. 가위는 엄지+검지입니다.
2. 양쪽 손을 보고 판단합니다. 승패 안내는 판정 후에만 나옵니다.
3. 망치는 **손잡이**를 누르고, 위로 들어 장전한 뒤 상대 정수리로 내려긋습니다. 냄비는 **손잡이**를 누르고 내 머리 위로 끌어 유지합니다. 잘못된 도구·무승부 도구·조기 출발은 파울입니다.
4. 마우스를 놓으면 해제됩니다. 냄비는 유지해야 방어가 계속됩니다. 망치를 놓고 끝내면 빗나감입니다. 결과 후 다시 시작 버튼으로 다음 판을 진행합니다.

`Esc`·포커스 상실·포인터 취소·창 크기/카메라 변경은 안전 해제합니다. 오른쪽에서 세 카메라, 관절 표시, 0.25배속, 상대의 큰 반대 손 동작·한 손/두 손 냄비를 고릅니다. 단독 재생은 시간 슬라이더로 정확한 프레임을 관찰할 수 있습니다.

## 기술 및 기준값

- Three.js **0.180.0**, npm 배포의 `three.module.min.js`·`three.core.min.js`를 vendor에 내장. [MIT 라이선스](vendor/LICENSE-three.txt). 두 파일 합계 720,032 bytes. 이미지·폰트·CDN 없음. ES module의 직접 상대 경로 import라 importmap이 필요 없습니다.
- 3D 골반 → 척추 2마디 → 목·머리, 쇄골 → 위팔 → 아래팔 → 5개 손가락(각 3마디). 쇄골·위팔·아래팔·척추 길이는 고정입니다. 상대 기본 손은 어깨 너머 시점에서 잘 보이는 쪽이고 큰 동작은 반대 손입니다.
- 두 마디 IK와 pole, 해부학적 어깨 방향 제한·팔꿈치 단방향 굽힘·쇄골 상승·척추 기울기. 범위 밖 목표는 닿는 지점에서 멈춥니다. 직접 입력은 아래·바깥 pole, 스크립트는 촬영 각도를 재구성하는 pole을 사용합니다.
- 손이 도구보다 먼저 움직입니다. 잡기는 손이 손잡이에 도달한 뒤 접속하며 약 0.1초에 손가락이 감깁니다. 도구 위치는 손 소켓과 같고, 회전만 25ms 지연하며 **실제 지연된 손목 각도**도 범위 안으로 제한합니다.
- 카메라 광선과 테이블/상대 정수리/내 머리의 3D 조작 평면 교차점에서 소켓 오프셋을 뺀 손 목표를 구합니다. 임계 감쇠 스프링은 90%까지 약 60ms(기본 ω=65). 클릭 한 번으로 공격/방어가 완성되지 않습니다.
- 판정은 표시하는 망치 머리의 3D 이동 구간·정수리 구·최소 속도/이동량·하강 방향을 검사합니다. 얼굴·느린 이동·위로 올리기·중복 타격은 거부합니다. 냄비는 실제 표시 위치·법선 방향·70ms 유지를 검사하고 이탈 즉시 해제합니다. 상대 냄비도 같은 판정을 사용합니다.
- hitstop 65ms, 관절로 계산한 목·머리의 0.45초 반동. 점수/에너지와 보스·트릭 규칙은 추가하지 않았습니다.

| 동작 | 촬영 기준 | 구현 |
| --- | --- | --- |
| 작게 흔들기 | 0.45~0.50s, 팔꿈치 안쪽 50~75° | 0.45s, 50~75° |
| 작게 내기 | 0.20~0.25s, 약 80° | 0.22s, 80°; 마지막 0.1s 손 공개 |
| 크게 내기 | 안쪽 120~140°, 위팔 50~60° | 130° / 55°, 몸통 12°·회전 10°, 반대 손 |
| 망치 잡기→충돌 | 0.65~0.80s | 0.73s = 들기 .20 + 장전 .20 + 펴기 .15 + 내려치기 .18 |
| 망치 장전·최고점·충돌 | 약 70~85°, 최고점 165°/105°, 끝에서 위팔 10~15° 하강 | 77°/92° → 165°/108° → 165°/95° |
| 냄비 한 손 | 0.27~0.30s, 안쪽55°·위팔70~78°, 고개 숙임 | .285s, 55°/75°, 목18° |
| 냄비 두 손 | 0.33~0.40s, 안쪽65~90°·위팔80~120° | .365s, 양팔65°/100°, 목0° |
| 냄비 내려놓기 | .30~.35s | .325s |

팔꿈치 제한 **0~145°는 굽힘량**이며, 촬영의 안쪽 각도는 `180° - 굽힘량`입니다. 촬영 165°는 굽힘 **15°**입니다. 디버그에는 둘 다 표시합니다. 관절 제한·주요 동작 각도·시간·입력·판정 수치는 [config.mjs](config.mjs)에서 조정합니다.

상대 공격은 손 공개 후 .32s 판단/잡기 준비 + .73s 망치 동작 = **1.05s**로 prototype 공격 시각을 유지합니다. 상대 방어는 착용 시간과 70ms 판정을 역산해 **1.10s 근처**에 준비됩니다. 실제 3D 위치가 맞아야 방어되므로 시간만으로 막았다고 판정하지 않습니다. 플레이어 이동 속도는 강제하지 않습니다.

가위바위보 단독 재생은 .5s 유지 후 .25s 복귀합니다. 실제 판에서는 도구 잡기가 시작되면 유지 동작을 중단합니다(상대 공격은 공개 후 .32s). 카운트도 3초가 아닌 측정한 .45s 두 박자와 .22s 공개 동작을 사용합니다.

## 재현 검사

```sh
node games/worlds-greatest-game/motion-lab/tests/unit.mjs
node games/worlds-greatest-game/motion-lab/tests/browser.cjs
```

브라우저 검사는 작업용 Playwright 1.56.1과 설치된 Chrome을 사용합니다. Playwright가 표준 경로에 없으면 `WGG_PLAYWRIGHT_PATH`를 설치 경로로 지정합니다. `WGG_VIDEO=1`로 영상도 기록합니다. 검사용 서버는 임시 포트를 열고 종료 시 닫습니다. 브라우저의 `window.motionLab`은 상태/투영 조회 전용이며 위치나 승패를 주입하지 않습니다. 테스트는 난수만 바위로 고정해 실제 버튼·포인터 입력을 보냅니다.

결과·한계는 [TEST_RESULTS.md](evidence/TEST_RESULTS.md), [브라우저 수치](evidence/browser-results.json), [플레이 녹화](evidence/motion-lab-review.webm)를 참고합니다.

## 한계

- 동작 검증용 캡슐/상자 마네킹이며 인체 피부·근육·몸체 충돌을 시뮬레이션하지 않습니다. 팔/몸·도구 사이 관통 방지는 별도 과제입니다. 어깨의 회전은 허용 원뿔과 pole로 제한하며 정교한 근골격 모델은 아닙니다.
- 손은 3D 조작 평면을 따릅니다. 원근 때문에 모든 카메라에서 손잡이가 커서와 완전히 겹치지는 않으며, 도달 범위 밖에서는 팔이 멈춥니다. 자유 회전 카메라는 없습니다.
- 본체·팔은 각 노드의 3D 좌표를 연결하는 고정 길이 도형이고, 손가락은 부모-자식 힌지 구조입니다. 스킨 메시가 아닙니다.
- 냄비 손잡이는 마우스 조작과 두 손 소켓을 위해 앞쪽으로 연장한 실험실 도형입니다. 실제 냄비 비례·그립 방향은 촬영 자료와 추가 조정이 필요합니다.
- 단독 재생의 "충돌"은 시간표의 단계 이름입니다. 직접 조작에서는 실제 공간 충돌이 발생해야 명중합니다.
- 태블릿/실물 마우스 손맛·장시간 플레이·다른 GPU/브라우저/Windows 게임 빌드·Steam은 미확인입니다. 자동 검사 통과를 손맛 완성으로 보지 않습니다.
