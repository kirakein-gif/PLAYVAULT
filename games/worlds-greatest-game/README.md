# 세계 최고의 게임 · THE WORLD'S GREATEST GAME

> 인류가 찾아낸 가장 공정한 승부. 그런데 왜 모두 냄비를 쓰고 있을까?

2D **카툰 × 극화체** 코미디 심리전 액션게임 기획 및 프로토타입 저장 폴더입니다. Steam용 PC 게임을 장기 목표로 합니다.

## 현재 상태 (2026-10-19)

- `prototype/index.html` — **1차 액션 프로토타입 v0.10 / APPROVED A**. 승인한 구도와 오른손 가위바위보를 유지하고, 도구 동작을 연결형 정지 포즈로 전환했습니다. 인물마다 망치 잡기·들기·내려치기 3장, 냄비 잡기·착용 2장. 테이블 도구 크기는 25% 확대했습니다. 화면 아래에서 양쪽 10개 포즈를 따로 볼 수 있습니다. 직접 마우스 스윙·착용 판정과 3점 경기를 유지하며 파일 실행을 지원합니다.
- 새 버전의 [실행·조작·검증 방법](prototype/README.md)과 [기술 선택 및 단계별 기록](docs/ACTION_PROTOTYPE.md)을 참고하세요. 아래 v0.1 원본은 보존했습니다.
- `index.html` — 이전 대화에서 만든 **HTML5 v0.1 테스트판** 원본. 브라우저에서 바로 열어 플레이할 수 있습니다.
- v0.1은 **아이디어 검증용**입니다. 현재의 단축키/버튼식 공격 및 승패 안내 UI가 정식 방향이라는 뜻이 아닙니다.
- 정식 목표인 마우스 **드래그·스윙 타격**, **냄비 직접 착용**, **3/4 어깨너머 카메라**, **직접 승패 판단**, **파울**, **고품질 극화체 애니메이션**은 앞으로 구현할 과제입니다.

### 실행

1. `index.html`을 다운로드합니다.
2. Windows PC의 Chrome, Edge 등 브라우저에서 엽니다.
3. 오프닝 및 기존 v0.1의 최주임/김과장 테스트를 플레이합니다.

기존 구현이 예전 규칙을 따르더라도, **이번 저장 시점의 기획 문서를 정식 요구사항으로 우선**합니다.

## 개발의 최우선 원칙

1. 캐릭터 일러스트 한 장보다 **동작이 살아 있는 애니메이션과 타격감**을 먼저 검증한다.
2. 플레이어가 상대 패를 보고 스스로 승패를 판단한다. 시스템이 '승리/패배'를 먼저 알려주지 않는다.
3. 망치는 마우스로 **집고 휘둘러** 상대 머리를 가격한다. 냄비는 마우스로 **집어 자신의 머리에 씌운다**.
4. 상대의 반칙은 관찰 가능한 징후와 웃기는 파훼법이 있다.
5. 등장인물들은 경기를 극도로 진지하게 여기고, 상황만 터무니없다.
6. 정식 그래픽: 진지한 카툰·극화체 혼합, 3/4 정면 상대와 플레이어 어깨너머 시점.
7. 새로운 기능은 **실제 플레이 검증 후** 추가한다. 스테이지 확장보다 손맛이 먼저다.

## 저장소 정책

- 본 게임 폴더는 `PLAYVAULT/games/worlds-greatest-game/`에만 둡니다.
- 기존 다른 게임, 공용 캐릭터, 메인 런처를 이번 초기 등록에서는 변경하지 않습니다.
- 플레이어/보스 아트, 음악, 폰트, 효과음의 **권리 및 제작 출처**를 기록하며 제3자 게임의 소스나 연출을 복제하지 않습니다.
- Steam 판매 전 별도 권리 점검, 설정/접근성/저장/로컬화/QA가 필요합니다.
- 코드·아트의 이용 허가는 아직 명시하지 않았습니다(무단 재배포 허가 아님).
