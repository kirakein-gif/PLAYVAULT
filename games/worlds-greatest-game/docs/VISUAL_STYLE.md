# 비주얼 스타일 가이드 v1.0

## 키워드

**'진지하게 그려진 인물, 터무니없이 과장되는 반응.'**

카툰 40% + 극화체 60%는 대략적인 무드 표현이며 기계적인 비율은 아닙니다. 만화적 질감과 장엄한 극화체 조명을 혼합합니다. 특정 기존 게임의 미술/캐릭터/모션은 복제하지 않습니다.

## 정지 화면

- 성인 비례, 진지한 얼굴 해부학, 턱선·눈썹·코의 개성 강조.
- 또렷한 실루엣, 깔끔한 외곽선, 셀 셰이딩 및 극적인 키라이트.
- 장소는 회사 교육장 → 대회장 → 국제 무대 → 올림픽으로 확장.
- 지나치게 어두운 고딕풍으로 가지 않으며, 코미디를 처음부터 노골적으로 드러내지 않는다.
- 읽기 쉬운 손 모양(가위/바위/보), 망치 머리, 냄비 입구·손잡이는 실루엣 단계에서 검증한다.

## 화면 구도

- 상대는 화면 중앙~우측의 **정면 3/4** 구도. 눈동자·두 손·피격 얼굴을 비교적 크게 보여준다.
- 플레이어는 아래/왼쪽에서 **뒷머리, 어깨, 팔 또는 다리 일부**만 보여주는 어깨너머 시점.
- 중앙 테이블 위에 망치와 냄비.
- 손을 공개할 때 상대/플레이어의 패가 동시에 보이도록 UI가 가리지 않는다.
- 방어 시 냄비를 씌워야 할 **플레이어의 머리 위치**가 실제로 보여야 한다.
- 피격 순간 짧은 카메라 줌/진동 후 즉각 정상 위치 복귀.

## 캐릭터 애니메이션

**정지 그림을 끌고 다니는 구현은 완성이 아니다.** 가능한 한 얼굴, 눈, 머리, 몸통, 어깨, 상완, 전완, 손목, 손가락을 분리한 고품질 본 리깅/IK 또는 프레임 애니메이션을 사용한다.

| 상태 | 동작 및 실루엣 |
|---|---|
| Idle | 호흡, 눈동자 움직임, 의상 미세 흔들림 |
| RPS 준비/공개 | 리드미컬한 손 동작 후 가위·바위·보를 명확하게 공개 |
| 도구 집기 | 손이 손잡이를 향해 다가가 손가락으로 고정 |
| 망치 스윙 | 예상 동작 → 가속 → 충돌 → follow-through → 복귀 |
| 냄비 방어 | 들어 올리기 → 머리 위 정렬 → 착용 → 충격에 덜컹 |
| 타격 | 짧은 히트스톱, 캐릭터 머리 눌림/반동, 소도구 탄성 |
| 피격 후 | 눈꺼풀/입/눈썹 변형, 모자/머리카락/넥타이 흔들림 |
| 반칙 파훼 | 김과장 눈동자 과도한 추적 → 빙글빙글 → 별/비틀거림 |
| 파울 | 심판의 호루라기, 당황/항의 표정, 짧은 템포 중단 |

### 연출 원칙

- **기본 얼굴은 진지함.** 맞기 직전 눈으로 망치를 추적하고 공포를 알아차린다.
- 접촉 프레임은 명료하게: 유효 충돌을 보여주고, 최소 몇 프레임은 임팩트를 인지할 수 있어야 한다.
- 과장된 squash & stretch는 피격/당황 등 **결정적인 순간**에만 적용한다.
- 타격 직전 준비와 타격 직후 반동의 길이를 각각 조절해 리듬을 만든다.
- 타격 강도 표현은 게임적 만화 스타일(피·잔혹함이 아닌 엉뚱한 충격 및 표정 변형).
- 파울·방어·빗나감·명중은 소리와 애니메이션으로 각기 구분한다.

## 색/해상도/UI

- 배경은 영화적인 중간 대비, 캐릭터는 충분히 밝고 뚜렷한 채도.
- 망치는 노랑/빨강, 냄비는 은색 금속광 등 한눈에 구별되는 상징색.
- PC 기준 1920×1080을 품질 기준으로 삼고 다양한 종횡비/배율을 지원한다.
- 픽셀/선 흐림, 노이즈, 비율 불일치, 잘린 팔다리, 레이어 뒤집힘을 피한다.
- 전투 중 텍스트 UI는 적게. 'WIN'을 띄워 직접 판단의 재미를 깨지 않는다.
- 마우스를 직접 사용하는 만큼 조준점/손잡이 접근 영역은 충분히 명확하게 표시.
- 명암/색상만으로 판정을 전달하지 말 것.

## 아트 제작 파이프라인

1. 세 가지 실루엣 테스트(플레이어 머리/손, 상대 손, 망치·냄비).
2. 같은 카메라 각도로 기본 서 있는 상대와 플레이어 팔 포즈 설정.
3. 파츠 레이어 및 피벗 좌표 고정(머리/어깨/팔꿈치/손목/손바닥).
4. RPS 손 모양을 각각 작업하고 3가지 모두 명확히 보이는지 테스트.
5. 집기·휘두르기·착용·피격을 블로킹 단계로 구현.
6. 완성 타격감 검증 후 최종 셰이딩/표정 파생·이펙트·사운드 작업.

에셋의 파일명, 출처, 제작 방식, 사용 권한을 추적 관리한다. Steam 출시 전 상업적 라이선스 검토가 필요하다.
