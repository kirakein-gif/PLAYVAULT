[이번 작업의 목적과 범위]
- 목적은 "손맛"의 바탕인 몸 동작 검증이다. 그림·반칙·보스·에너지 체계·연출 완성은 범위 밖이다.

[기술]
- 3D 계산 필수: 어깨 너머 시점에서 내려치기는 상대 쪽(화면 안쪽)으로 그리는 호라서 평면 2D 관절로는 재현할 수 없다(MOTION_REFERENCE 2절 시사점 1).

- 회색 마네킹: 캡슐·상자 등 단순 도형. 두 사람이 테이블을 사이에 두고 앉은 장면, 테이블 위 뿅망치와 냄비.
- 카메라 3개 전환: ① 게임 시점(플레이어 오른쪽 어깨 너머, 상대는 3/4 정면 — prototype v0.13 구도와 비슷하게) ② 측면 ③ 정면(상대 시점). 마우스 휠/키로 자유 회전 카메라는 선택.

[골격 — 두 인물 공통]
- 골반(앉은 자세 고정) → 척추 2마디 → 목 → 머리. 양쪽 쇄골 → 위팔 → 아래팔 → 손.
- 손가락 5개, 각 2~3마디(엄지 포함). 가위=엄지+검지(ㄴ자, MOTION_REFERENCE 1절·0-1절), 바위=주먹, 보=다섯 손가락 펴서 벌림.
- 뼈 길이는 절대 늘어나거나 줄지 않는다(자동 검사 대상).
- 관절 가동 범위(설정 파일에서 조정 가능하게):
  팔꿈치 굽힘 0~145°, 한 방향만(반대로 꺾임 금지)
  손목 굽힘/젖힘 약 ±70°, 좌우 약 -20°~+30°
  어깨는 해부학적으로 불가능한 비틀림 금지, 위팔을 들 때 쇄골이 함께 올라가게
  척추 앞숙임·회전, 목 숙임은 작은 범위로

[팔 계산]
- 3D 두 마디 IK(위팔·아래팔) + 팔꿈치 방향(pole) 제어. 팔꿈치는 자연스럽게 아래·바깥을 향한다.
- 손이 팔 길이보다 먼 목표를 따라가면 팔을 늘리지 말고 쇄골·척추 기울기로 보충하고, 그래도 안 닿으면 닿는 곳까지만 간다.
- 손이 도구를 끌고 간다(도구가 손을 끌면 안 됨). 도구는 손바닥 소켓에 붙고, 잡는 순간 약 0.1초 동안 손가락이 손잡이를 감싼다.
- 도구는 무게감 있게 손보다 아주 조금 늦게 회전한다(과하지 않게, 수치 조정 가능).

[마우스 → 손 목표점 (플레이어)]
- 권장 방식: 커서에서 카메라 광선을 쏘아 "조작 표면"(테이블 윗면, 상대 머리 주변, 내 머리 위 영역, 그 밖은 보조 면)과 만나는 3D 점을 손 목표로 쓴다.
  즉 화면에서 상대 정수리를 가리키면 손이 실제 3D 공간의 상대 정수리 쪽으로 간다.
- 손은 목표를 임계 감쇠 스프링으로 따라간다. 목표의 90%까지 80ms 이내(조정 가능). 입력이 늦게 느껴지면 실패다.
- pointerdown/move/up, pointer capture, coalesced events, 창 이탈·포커스 상실 시 안전 해제(prototype v0.13의 처리 방식 참고).

[동작 — MOTION_REFERENCE 측정값 기준, 모두 설정 파일에서 조정 가능하게]
1. 가위바위보 · 작게(기본, 양쪽 모두)
   - 흔들기: 팔꿈치 약 50°↔75°, 손목은 어깨 높이 근처, 한 주기 약 0.45초, 두 번 흔들고 세 번째 박자에 낸다. 흔드는 동안 주먹.
   - 내기: 팔꿈치 약 80° 안팎, 손은 가슴 앞. 손 모양은 내는 동작의 마지막 약 0.1초 동안 펴진다(그 전까지 주먹 → 손 모양이 일찍 새지 않음).
   - 유지 약 0.5초, 복귀 0.2~0.3초.
   - 플레이어: 카운트 중 1/2/3 또는 버튼으로 고른 손을 이 동작으로 낸다(prototype v0.12의 3→2→1 예약 방식 참고).
2. 가위바위보 · 크게(상대 전용 옵션, 반대쪽 손)
   - 팔이 상대 쪽으로 거의 펴짐(팔꿈치 약 120~140°, 위팔 약 50~60°), 몸통이 앞으로 기울고 돌아감.
   - 이번에는 상대 설정에서 고를 수 있는 동작만 만든다. 트릭 규칙(반칙 판정)은 만들지 않는다.
3. 망치(플레이어는 마우스, 상대는 같은 궤적을 스크립트로)
   - 순서: 잡기 → 들기(약 0.2초) → 머리 옆 장전(팔꿈치 약 70~85°, 손목이 어깨보다 위, 약 0.2초) → 팔을 펴며 최고점(팔꿈치 약 165°, 위팔 약 105°) → 마지막 0.15~0.2초에 위팔이 10~15° 내려가며 팔이 수평일 때 정수리에 충돌.
   - 잡기~충돌 0.65~0.8초(상대 스크립트 기준값).
   - 플레이어는 마우스로 직접 움직이되, 빠르게 내리긋는 순간 손목이 꺾이는 스냅이 손 속도에 따라 자동으로 섞이게 한다(입력보다 앞서 가지는 않는다).
   - 충돌: 망치 머리와 상대 정수리의 3D 충돌 + 최소 속도/방향/이동량 검사(수치는 설정). 한 번만 판정. 정수리가 아닌 얼굴을 친 것은 명중이 아니다.
   - 충돌 순간 짧은 정지(hitstop)와 맞은 쪽 머리·목이 실제로 눌렸다 돌아오는 반동(관절로 계산).
4. 냄비
   - 플레이어: 한 손. 머리 위까지 약 0.27~0.3초가 자연스러운 속도. 팔꿈치 약 55°로 깊게 굽히고 위팔 약 70~78°, 아래팔이 머리 위를 덮는다. 냄비가 머리 위에 오면 **고개를 앞으로 숙인다**.
   - 상대: 설정으로 한 손(위와 같음) 또는 두 손(약 0.33~0.4초, 양 팔꿈치 약 65~90°, 위팔 약 80~120°, 고개 똑바로).
   - 착용 판정은 3D 위치·방향·유지 시간(설정).
   - 내려놓기 약 0.3~0.35초.

[최소 한 판 흐름 — 손맛 확인용]
- 3→2→1 카운트 → 양쪽 손 공개 → 플레이어가 직접 판단 → 망치 또는 냄비 → 판정 → 다음 판.
- 승패를 글자로 먼저 알려주지 않는다. 판정 후 결과 문구만.
- 상대 패는 난수, 상대 방어/공격 타이밍은 설정값(초기값은 prototype v0.13의 enemyGuardMs 1100, enemyStrikeMs 1050 참고하되, 상대 망치 동작 길이 0.65~0.8초와 맞게 조정하고 이유를 적는다).
- 잘못된 도구 = 파울, 무승부에 도구 = 파울(prototype 규칙 유지). 에너지·점수 체계는 최소로.

[디버그 화면 — 필수]
- 관절 점·뼈 표시 켜기/끄기, 주요 관절 각도 숫자(팔꿈치·위팔·손목·목), 가동 범위 위반 횟수(0이어야 함).
- 슬로 모션 0.25배, 카메라 전환, 상대 동작 단독 재생(가위바위보 작게/크게, 망치, 냄비 한 손/두 손).
- 상대 스크립트 동작의 시간 그래프(각 단계 시작/끝)와 MOTION_REFERENCE 기준값 비교 표.

[검사]
1. Node 단위 검사
   - 무작위 목표 1만 개 이상: 뼈 길이 불변(오차 1e-6 이내), 팔꿈치 0~145° 한 방향, 손목 범위 준수.
   - 손 모양 3종의 손가락 상태(가위=엄지+검지만 펴짐).
   - 스크립트 동작 시간이 MOTION_REFERENCE 기준값 ±0.05초 이내(설정 기본값 기준).
   - 판정: 정수리 명중/얼굴 빗나감/느린 이동 거부/한 번만 판정/파울/냄비 착용·이탈.
2. 브라우저 검사(Playwright, 실제 pointer 이벤트)
   - 망치 잡고 정수리로 휘둘러 명중, 냄비 잡아 머리에 써서 방어, 잘못된 도구 파울, 취소·창 크기 변경.
   - 외부 요청 0, 콘솔 오류 0, 동작 중 가동 범위 위반 0.
   - 세 카메라에서 핵심 순간 캡처(가위바위보 공개, 장전, 충돌, 냄비 착용) — PR에 첨부.
3. 성능: 일반 PC 브라우저에서 60fps 유지 여부를 측정해 적는다.

[보고]
- PR 본문: 실행 방법(저장소 루트에서 정적 서버로 motion-lab/ 열기), 조작법, 기술 선택 근거, 측정값과 실제 구현값 비교표, 검사 결과(통과/실패/미실행 구분), 한계.

## 이후 단계(이번 지시 범위 밖)

1. 사용자가 실험실을 직접 해 보고 손맛 판정 → 필요하면 추가 수정 지시.
2. 통과하면 아트 방식 결정: 3D 골격 계산 + 2D 조각 그림, 또는 3D 모델 + 만화풍 셰이딩.
3. 그다음 상대 트릭(크게 내미는 반대 손), 반칙·파훼, 보스 확장.
