# 개발 로드맵 · 완료 기준

이 문서는 범위를 통제하기 위한 가이드입니다. 일정·예산·판매 성과를 보장하지 않습니다. **한 판의 재미**를 먼저 검증한 뒤 확장합니다.

## 현재 단계: v0.1 보존 및 개발 준비

- [x] HTML5 v0.1 브라우저 테스트 원본 보존 (`../index.html`)
- [x] 기획, 화풍, 입력, 애니메이션, 보스 반칙 핵심 기준 문서화
- [ ] 코덱스가 기술구조 검토: 기존 HTML5 진화 vs Godot 2D 이관
- [ ] 실측 입력/애니메이션 검증 계획 수립 및 코드 기준선 정리

## 1차: 상호작용 가능 프로토타입

**목표: 상대 1명만 있어도 망치와 냄비를 조작하는 재미.**

- [ ] 상대 정면 3/4 + 플레이어 어깨너머 카메라 블로킹
- [ ] 내 손과 상대 손의 가위/바위/보 3종 애니메이션
- [ ] 승패 자동 노출 제거, 게임 규칙 내부 판정만 유지
- [ ] 망치 grab + 팔 연동 + 실제 스윙 궤적/상대 머리 충돌 판정
- [ ] 냄비 grab + 팔 연동 + 자신의 머리 착용 영역 판정
- [ ] 가위바위보 결과에 따른 도구 파울 및 심판 판정
- [ ] 반복해도 안정적인 입력/상태 전환
- [ ] 기본 hitstop/반동/표정/효과음
- [ ] Windows 크기·해상도별 수동 플레이 검증

**완료 조건:** 망치/냄비를 버튼이 아닌 **마우스 손동작으로** 매끄럽게 사용하고, 제대로 이겼는지 **스스로 보고** 판단할 수 있을 것.

## 반드시 지킬 원칙

- 사용자가 원하지 않는 **성급한 10보스 확장**, 대량 UI 추가, 임시 에셋을 완성이라 발표하는 작업을 금지.
- 기능 구현 후 반드시 플레이 테스트로 타격감/조작감을 평가. 코드 테스트 통과만으로 '상업용 완성도'라고 표현하지 않는다.
- 중요한 설계 변경 전 해당 문서와 변경 이유를 먼저 업데이트한다.
