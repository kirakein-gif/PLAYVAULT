# Codex 작업 전달 — 첫 실행 안내

## 저장소 및 작업 범위

- GitHub: `kirakein-gif/PLAYVAULT`
- 작업 대상: `games/worlds-greatest-game/`
- 현재 플레이 가능 기준선: `games/worlds-greatest-game/index.html` (구 HTML5 v0.1)
- 읽을 문서: `README.md`, `docs/GAME_DESIGN.md`, `docs/VISUAL_STYLE.md`, `docs/COMBAT_AND_INPUT.md`, `docs/ROADMAP.md`
- 사용자는 다른 게임의 수정이나 PLAYVAULT 전체 리팩터링을 요청하지 않았다.

**규칙: 기존 다른 게임 코드, PLAYVAULT의 공용 아트·캐릭터 및 메인 런처는 허가 없이 수정하지 말 것.**

## 첫 지시: 우선 살펴보고 한 판을 완성하라

기존 v0.1 HTML은 게임 세계관과 오프닝 등의 **콘셉트 테스트**를 재사용할 수 있으나, 조작감의 정식 기준은 아니다.

다음 목표를 수행한다.

1. v0.1 코드 구성, 의존성, 입력/상태/렌더링을 분석한다.
2. **HTML5 개선 vs Godot 2D 전환**을 비교한다. PC 마우스 조작, 2D 본·IK/프레임 애니메이션, Steam Windows 배포, 유지보수, 사용자가 확인하기 쉬운 테스트 방식 기준으로 선택 근거를 적는다.
3. 기존 `index.html`을 덮어쓰기 전에 별도 브랜치 또는 신규 경로에서 **1차 조작 프로토타입**을 개발한다.
4. **승패 안내를 먼저 띄우지 않는다.** 플레이어가 양측 손을 보고 직접 판단한 뒤 행동한다.
5. 실제로 **잡고 끌어 휘두르는 망치**, **집어 자기 머리에 씌우는 냄비**가 작동해야 한다.
6. 플레이어/상대의 팔 움직임을 도구와 연결하고, 3/4 어깨너머 시점을 적용한다.
7. 맞음/막음/빗나감/파울을 확실히 구분하고, 히트스톱/반동/소리/표정의 타격감을 구현한다.
8. **최주임 1명** 또는 더 단순한 훈련용 상대 한 명으로 구현한다. 김과장/10보스는 아직 확장하지 않는다.
9. 검증 방법(실행 절차, 재현 시나리오, 완료된 기능, 한계 및 미완료)을 커밋 설명과 함께 보고한다.

## 우선 구현해야 할 최소 수직 슬라이스

- 로컬에서 실행되는 한 경기 화면
- RPS 양측 손 공개(승패 텍스트 없음)
- 마우스 포인터다운/드래그/스윙/포인터업 처리
- 스윙 궤적 및 상대 머리 충돌 판정
- 냄비 머리 착용/방어 판정
- 올바른/틀린 도구 파울 판정
- 간단하지만 분명한 캐릭터 팔·머리·표정 모션, 피격 반동
- 사운드 및 플레이 방법 안내(정답 누설은 금지)

## 중요한 실패 방지 지침

- 도구 그림만 커서에 따라 이동하고 팔은 안 움직이는 형태를 완료로 보고하지 않는다.
- 클릭 한 번으로 망치가 자동 공격하거나 냄비가 자동 착용되는 버전은 정식 핵심 조작의 완료로 보지 않는다.
- 미구현/임시 그래픽을 고품질 완성 아트로 소개하지 않는다.
- '윈도우 게임 완성' 또는 'Steam 출시 가능'이라고 검증 없이 단정하지 않는다.
- 소스에 API 키나 비밀번호를 넣지 않는다.
- 유료/제3자 아트·음원을 무단 사용하지 않는다.
- 판정 조건은 고정 숫자 하드코딩 대신 나중에 조정 가능한 형태로 나눈다.
- 브라우저 툴 등 실제 실행 검증이 불가능하면 코드 검사만 했다고 분명하게 보고한다.
