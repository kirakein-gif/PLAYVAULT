# 동작 기준 · 실제 사람 촬영 분석 v0.1

2026-11-05 사용자가 직접 촬영한 영상 4개(가위바위보 정면·측면, 내려치기 측면·정면)를 분석한 기록입니다. **게임의 팔·손 동작은 이 문서의 실제 관절 움직임을 기준으로 만듭니다.** 사용자 결정(2026-11-05): 반칙·파훼·보스 확장보다 기본 동작(가위바위보 → 잡기 → 내려치기/막기)의 사실적 구현이 우선입니다.

- 원본 영상과 얼굴이 나온 캡처는 개인 자료이므로 저장소에 올리지 않습니다. 이 문서에는 측정값만 남깁니다.
- 영상은 약 30fps(프레임 간격 33ms)이므로 시간 오차는 ±0.03초입니다.
- 도구: MediaPipe Pose(heavy) / Hand Landmarker 1.2.2. **손 추적은 정확했으나 몸(어깨·팔꿈치) 추적은 어깨·머리가 화면 밖이라 실패**하여 사용하지 않았습니다. 팔꿈치·어깨 각도는 프레임을 눈으로 본 근사치입니다.
- 손목 속도(px/s)는 960px 폭으로 축소한 화면 기준의 상대값입니다. 카메라 거리에 따라 달라지므로 영상 안에서의 비교에만 씁니다.

## 1. 가위바위보

| 단계 | 측정 | 관절 움직임 |
|---|---|---|
| 흔들기(펌프) | 위아래 한 주기 **약 0.45~0.5초**. 내려갈 때 손목 최고 약 1,100px/s. 2회 흔든 뒤 세 번째 박자에 내밈 | 위팔은 거의 고정, **팔꿈치를 굽혔다 폈다**하며 아래팔이 위아래로 흔들림. 주먹을 쥔 상태 유지 |
| 내밀기 | 정점에서 뻗을 때까지 **0.2~0.25초**, 최고 약 1,500px/s | 팔꿈치가 거의 펴지고(약 170°) 어깨가 앞으로 들려 팔이 수평으로 상대를 향함 |
| 손 모양 완성 | 내밀기의 **마지막 약 0.1초** 동안 손가락이 펴짐. 그 전까지는 주먹 | 펼친 손가락은 도착 순간 완성 |
| 유지 | 약 0.5초 정지 후 0.2~0.3초 만에 빠르게 복귀 | |

- **가위는 엄지+검지(ㄴ자) 방식**입니다(측면 2.91초: 엄지·검지만 펴짐). 검지+중지 방식이 아닙니다.
- 보는 다섯 손가락을 펴고 손바닥이 옆/아래를 향한 채 앞으로 뻗습니다.
- 게임 설계 시사점: 흔드는 동안 주먹이라 손 모양이 숨겨지고, 내미는 마지막 순간에 드러납니다. 손 공개를 그림 교체가 아니라 **이 동작 안에서** 보여 주면 "직접 읽고 판단"하는 긴장이 자연스럽게 생깁니다.

## 2. 망치 잡기와 내려치기

측면(옆에서 촬영) 기준:

| 단계 | 시각 | 측정·관찰 |
|---|---|---|
| 잡기 | 0.5~0.6초 | 팔을 앞아래로 뻗어 손잡이를 감싸 쥠(손 전체로 쥐는 파워 그립) |
| 들어 올리기 | 0.6~0.8초 | 팔꿈치가 먼저 굽으며 도구가 몸 쪽·위로 |
| 머리 위 준비 | 0.8~1.7초 | 팔이 머리 위로(화면 밖). 시연에서는 약 0.9초 멈춤 |
| 내려치기 | 1.74→2.01초, **약 0.27초** | 손목 최고 약 1,650px/s(1.88초, 중간 지점). 팔꿈치가 펴지면서 호를 그리며 앞으로 내려옴 |
| 충돌·정지 | 2.0초 이후 | **팔이 어깨 높이에서 수평으로 쭉 펴진 상태**로 멈춤. 손목이 꺾여 도구 머리가 앞을 향함 |

정면(상대 시점) 기준:

| 단계 | 시각 | 관찰 |
|---|---|---|
| 잡기 → 들기 | 0.4→0.75초 | 매우 빠름(카메라 가까이에서 손목 2,000~3,000px/s) |
| 어깨 옆 장전 | 0.75~1.05초(약 0.3초) | 위팔은 옆으로 들리고 팔꿈치 약 90°, 도구는 머리 옆에 세워 듦 |
| 머리 위로 | 1.1~1.3초 | 팔이 위로 거의 펴짐 |
| 상대 쪽으로 | 2.0~2.5초 | 도구가 카메라(상대) 쪽으로 다가오며 내려옴 |

시사점:

1. **내려치기는 상대를 향해 앞뒤(깊이) 방향으로 그리는 호**입니다. 어깨 너머 시점에서는 이 움직임 대부분이 화면 안쪽으로 들어가므로, 평면 2D 관절 계산으로는 재현할 수 없습니다. 최소한 **계산은 3D 골격**으로 해야 합니다.
2. 동작 순서는 **잡기 → 팔꿈치 굽혀 들기 → 어깨 옆 장전 → 머리 위 → 팔꿈치 펴며 호 → 수평에서 충돌**입니다. 속도는 호의 중간에서 가장 빠릅니다.
3. 시연의 잡기~충돌은 약 1.4초입니다. 현재 프로토타입의 공격 가능 시간(손 공개부터 1.1초, 판단 시간 포함)보다 깁니다. 실제 경기 속도의 빠른 동작은 머리 위까지 가지 않는 **짧은 호**일 가능성이 높습니다. 빠른 경기 속도로 다시 촬영해 확인이 필요합니다.

## 4. 다시 촬영할 때의 조건(몸 관절 측정용)

1. 머리, **양 어깨**, 몸통, 팔 전체가 처음부터 끝까지 화면 안에 들어오게 합니다. 이번에 몸 추적이 실패한 직접 원인입니다.
2. 휴대폰을 고정하고(거치대) 2~3m 떨어져 찍습니다. 60fps 이상이면 더 좋습니다.
3. 각도: 측면(90°), 정면, 그리고 가능하면 **게임 화면과 같은 어깨 너머 각도**.
4. 동작: ① 가위바위보 ② 망치 내려치기를 **실제 경기 속도**로 빠르게 ③ **냄비 잡아 머리에 쓰기** ④ 가능하면 두 사람이 테이블을 사이에 두고 실제로 한 판.
5. 실제 뿅망치·냄비가 없으면 비슷한 길이·무게의 물건을 써도 됩니다.
