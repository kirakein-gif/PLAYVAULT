# 게임 디자인 문서 v1.0

## 핵심 컨셉

**위대한 스포츠인 척하는 가위바위보 뿅망치·냄비 결투.** 가위바위보로 승패를 정하되, 결과를 시스템이 알려주지 않고 플레이어가 상대 손을 읽어 즉시 도구를 선택·조작합니다. 상대의 치사한 습관을 관찰하고 파훼하는 코미디 보스러시입니다.

### 게임의 두 개의 긴장감

1. **인지:** 동시에 공개된 내 손과 상대 손을 보고 누가 이겼는지 즉시 판단한다.
2. **동작:** 결과에 맞게 망치를 집어 휘두르거나 냄비를 잡아 머리에 씌운다. 타이밍과 궤적이 유효해야 한다.

서툴면 도구를 잘못 집어 파울을 범하거나 허둥대다 공격을 놓칩니다. 리액션은 강하게, 기본 조작의 판정은 정직하고 예측 가능하게 만듭니다.

## 오프닝

- 전쟁과 결투를 통해 인류는 승부의 기준을 찾아왔다.
- 힘, 계급, 돈, 무기 등이 승부를 기울게 했고 완벽한 공정함은 실패했다.
- 마침내 발견한 '세 선택의 완벽한 균형'을 인류 최고의 발명처럼 웅장하게 선언한다.
- 타이틀 **《세계 최고의 게임》** 공개.
- 나레이터: "이제 시작해 볼까요?"
- 웅장한 음악이 끊기고, 갑자기 익숙한 **가위 / 바위 / 보** 버튼이 보인다.
- 첫 판이 끝나자 망치와 냄비가 나타나며 두 번째 황당한 반전을 준다.

**핵심 연출:** 게임 속 사람들은 끝까지 진지하다. 대사로 억지 개그를 설명하지 않는다.

## 배경과 성장

처음에는 회사 신입사원 교육. 사내 승진 토너먼트 → 전국 직장인 선수권 → 세계선수권 → 올림픽 등으로 점점 과장된다. 중세 기사 전통을 주장하는 해외 선수도 등장할 수 있다. 장소가 커질수록 장엄한 연출이 강화되는데, 하는 일은 여전히 뿅망치와 냄비다.

## 보스 예시 10인 (개발 우선순위와 다름)

| 순번 | 가칭 | 특성/반칙 | 관찰 단서 및 파훼 |
|---:|---|---|---|
| 1 | 친절한 최주임 | 튜토리얼, 대체로 정직 | 기본 가위바위보/공격·방어 연습 |
| 2 | 성질 급한 박대리 | 가짜 출발 신호 | 심판의 실제 시작 신호를 읽는다 |
| 3 | 무패의 김과장 | 커서가 가리키는 패를 눈으로 훔쳐본다 | 마우스를 빠르게 왕복해 눈을 어지럽힌다. 별이 빙글빙글 돌며 일시적인 빈틈 발생 |
| 4 | 규정의 오부장 | 불리하면 결재창을 띄운다 | 자신에게 유리한 '반려' 처리 |
| 5 | 눈치 보는 심판의 최상무 | 편파 판정을 유도 | 영상 판독으로 증거 확인 |
| 6 | 마술사 손선수 | 소매 속 가짜 손을 교체 | 진짜 손의 그림자를 관찰 |
| 7 | 철벽의 강철두 | 냄비를 과하게 준비 | 거짓 공격으로 장시간 방어를 유도 |
| 8 | 폰 냄비 경 | 중세 왕실 규정 위조 | 두루마리 위조 흔적 확인 |
| 9 | 닥터 뿅 | 자동 망치/방어 장치 | 과열 유도 후 폭주 |
| 10 | 무명 씨 | 반칙이 전혀 없는 정직한 고수 | 순수한 관찰력과 손기술 승부 |

### 반칙 디자인 원칙

- 상대가 반칙하는 이유가 캐릭터 성격에 맞아야 한다.
- 플레이어가 직접 관찰할 수 있는 **시각적 단서**가 필요하다.
- 파훼는 시도할 수 있는 **직접 행동**이어야 하며 힌트 없이도 발견 가능해야 한다.
- 파훼 성공 시 우스꽝스럽고 풍부한 애니메이션 리액션을 제공한다.
- 파훼 성공이 즉시 승리여서는 안 된다. 가위바위보와 마우스 조작을 여전히 해내야 한다.
- 파훼를 몰라도 부당한 강제 패배만 반복되는 구조는 피한다.

## 기본 경기 흐름

대기 → 가위바위보 선택 → 양 선수 손 공개 → 플레이어 자체 판단 → (승리 시 공격 / 패배 시 방어 / 비김 시 리셋) → 유효 타격/방어/실수/파울 판정 → 양 선수 리액션 → 다음 라운드.

**금지:** 상대 패가 보이기 전에 친절한 텍스트로 결과를 공개하는 것, 단순 버튼을 누르면 공격/방어가 자동 완료되는 것.

## 개발 시 검증해야 할 질문

- 양손이 동시에 펼쳐질 때 플레이어가 손 모양을 **오해 없이** 읽을 수 있는가?
- 망치를 잡아 상대 머리에 내리칠 때 몸 전체의 움직임과 타격음이 납득되는가?
- 냄비를 머리에 놓는 동작이 자연스럽고 너무 어려워 불쾌하지 않은가?
- 유효한 파울/미스 판정과 억울한 오판이 구분되는가?
- 김과장의 눈동자가 커서를 따라가는 것을 플레이어가 스스로 알아차릴 수 있는가?
