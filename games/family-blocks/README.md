# BLOCK MASTER — 가족 블록 게임 (혼자 하기 1차)

CHESS MASTER와 별도로 설치되는 **완전 오프라인** Android 태블릿 앱(**세로 고정**, 2026-11-05 가족 요청) + PC 웹 버전입니다.
광고·서버 업로드·계정·네트워크 권한 없음. 두 사용자(아빠/아이)의 언어, 설정, 기록은 각자 저장됩니다.
앱 식별자: \`com.playvault.familyblocks\` (변경 금지), 버전: 1.0.0.

## 게임 모드
- **차근차근:** 레벨 1~5 고정. 꼭대기가 막혀도 판 위쪽 절반을 비우고 계속합니다. 메뉴의 그만하기로 기록을 저장합니다.
- **도전:** 레벨 1~10에서 시작, 10줄마다 레벨이 올라갑니다. 꼭대기가 막히면 종료.
- **40줄 달리기:** 레벨 1 고정. 40줄을 지우면 완료, 막히면 실패. 완료한 게임만 최단 시간을 저장.

## PC 웹과 태블릿 조작
- 태블릿: 왼쪽 아래 **← ↓ →**, 오른쪽 아래 **↺ ↻ 즉시 내리기**, 오른쪽 위 **보관**. 동시에 두 손가락 사용 가능. 일시정지 메뉴에서 계속·다시 시작·그만하기.
- 키보드: ←→ 이동, ↓ 소프트 드롭, Space 하드 드롭, ↑/X 시계 회전, Z 반시계 회전, C/Shift 보관, Esc/P 일시정지.
- 화면 배치: 세로(높이 > 너비)면 판을 가운데 크게, 보관·시간·줄은 왼쪽, 다음 블록·점수·레벨은 오른쪽, 터치 버튼은 아래. 가로(PC 웹)면 기존 배치. 폭 480px 미만(휴대폰)은 안내 화면.
- 전체화면: 머리글의 전체화면 버튼 또는 설정. APK는 상태 표시줄·하단 버튼을 숨기고 사용자별로 저장(다음 실행에도 적용), PC 웹은 브라우저 전체화면.
- Android 16 이상 큰 화면은 방향 고정을 무시할 수 있어 호환 속성(`PROPERTY_COMPAT_ALLOW_RESTRICTED_RESIZABILITY`)을 넣었고, 돌아가더라도 가로 배치로 그려집니다.
- 홀드는 블록 하나당 1회, 다음 블록 3개 미리 보기(설정에서 1개 선택), 착지 윤곽선 표시(끄기 가능).
- 배경 음악: 자체 작곡 짧은 반복곡. 진동은 앱에서만 노출합니다.

## 로컬 개발
Node 22, Android 빌드는 JDK 21 + SDK 36이 필요합니다.
\`\`\`bash
cd games/family-blocks
npm ci
npm test
npm run dev
npm run build
npm run build:web                 # play/ 갱신 (루트에서는 카드 미등록)
npm run test:e2e                 # Playwright 설치 시 브라우저 검사
npm run android:debug            # Android Studio / SDK 필요
\`\`\`
CI: \`.github/workflows/family-blocks-android.yml\`. APK: \`FamilyBlocks-v1.0.0-debug.apk\` (고정 가족 키), Release 태그 \`family-blocks-v1.0.0\`.
브랜치 \`chatgpt/family-blocks-solo\`의 PR 검토 후 사용자 승인으로 main에 병합하면 Release가 발행됩니다.

## 데이터 이동
설정 → 기록 내보내기(JSON) → 파일을 보관한 뒤, 새 기기의 앱에서 설정 → 기록 불러오기.
기록 지우기는 두 번 확인합니다. 앱 기록은 웹 브라우저와 서로 자동 동기화하지 않습니다.

저작권: 원목 칸 무늬는 코드로 그리며, 배경음과 효과음도 Web Audio로 직접 합성했습니다.
글꼴 라이선스는 \`LICENSES/\`, 음악 제작 기록은 \`docs/MUSIC.md\`를 확인하세요.
