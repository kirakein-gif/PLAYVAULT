## 확정된 제작 방향

- 중세 룩은 단순 성탑 대신 **성벽 위에서 방패를 든 병사**. 나이트는 말머리 대신 **말 탄 기사**, 앞발을 들고 일어서는 자세이며 **손에 창이 보임**. 이전 걷는 자세도 비교용 원화/변형으로 보존.
- 마지막 사진 기반의 사실적·풍화된 갑옷 조각상 세트를 **노블**이라고 부름. 사진에서 보이는 조형·재질·비율을 최대한 가까이 맞추라는 사용자 후속 지시가 초기의 일반적인 독자 디자인 방향보다 우선함. 가려진 부분은 재구성했으므로 원본과 픽셀 단위 동일 복원이라고 표현하지 않음.
- 노블 진영은 분명히 구분: 밝은 쪽은 기존보다 **흰색에 가깝게**, 어두운 쪽은 **검은색에 가깝게**. 재질의 회색 음영과 마모는 유지.
- 세트마다 맞는 밝은/어두운 **1024×1024 바닥 텍스처**를 함께 제공. 기물을 가리는 강한 무늬·갈라진 선·발광·금박은 피함.
- 기물은 **투명 WebP256×256**, 바닥 중심 정렬·받침 아래 기준235px. 실제 판의 약60px 크기에서 두 칸 색 모두 확인. 전체 코덱스 스킨 용량3MB 이내를 목표로 유지.
- `src/skins.ts`에는 기존 Claude `classic/wizard/gothic` 항목을 보존하고 세 Codex 항목만 추가. 설정 카드의 만든 쪽 표시는 기존 `author:'Codex'` 기능 사용. UI 색·게임 규칙·기존 SVG/CSS 수정 없음.
- 메뉴 상세 일러스트는 **기물 선택 후** 진행하는 별도 작업. 이번에는 기존 메뉴의 기물 표시 대체 기능을 사용하며 `menuArt`는 등록하지 않음.
