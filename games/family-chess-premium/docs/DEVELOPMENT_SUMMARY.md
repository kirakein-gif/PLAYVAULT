# CHESS MASTER · 개발 정리 (2026-11-02 ~ 2026-11-04)

아빠와 아들이 함께 두고 함께 배우는 **완전 오프라인 Android 태블릿 체스**. 이 문서는 지금까지 만든 것, 가족이 정한 것, APK 보관 위치를 한 곳에 모은 요약이다. 세부 기록은 맨 아래 "문서 지도"를 따른다.

## 1. APK 받는 곳 (영구 보관)

| 위치 | 보관 기간 | 비고 |
| --- | --- | --- |
| **GitHub Releases → `family-chess-v1.0.0`** | **영구** | main에 반영될 때마다 CI가 테스트 통과 후 APK와 SHA-256 파일을 자동으로 올림(같은 버전이면 파일 교체) |
| Actions 실행의 Artifacts `FamilyChessPremium-v1.0.0-debug-apk` | 90일 | 브랜치 빌드 확인용 |

주소: https://github.com/kirakein-gif/PLAYVAULT/releases/tag/family-chess-v1.0.0

설치: APK를 태블릿으로 옮겨 탭 → 처음이면 "출처를 알 수 없는 앱 설치" 허용. 인터넷 권한이 없는 앱이다.

### 서명 키 (2026-11-04 고정)

- 2026-11-03까지의 APK는 빌드마다 서명 키가 달라 **새 APK를 덮어 설치할 수 없었다**.
- 가족 결정으로 고정 키 `android/family-chess.keystore`를 저장소에 함께 보관한다(공개 저장소, 개인 설치용). 인증서 SHA-256 `BC:65:8C:09:33:D0:A9:CD:ED:EC:D6:59:26:F5:EB:14:C5:C7:67:88:2F:65:FC:83:17:29:57:72:D5:3E:8A:6A`, 유효 30년. CI가 매 빌드 이 지문을 확인하고 다르면 실패한다.
- **딱 한 번 필요한 절차:** 이미 설치된 이전 APK가 있으면 ① 설정 → 기록 내보내기 ② 앱 삭제 ③ 고정 키 APK 설치 ④ 설정 → 기록 불러오기. 이후 업데이트는 덮어 설치로 기록이 유지된다.
- Play 스토어에 올리려면 별도의 비공개 키가 필요하다(이 키는 쓰지 않는다).

## 1-2. PC 웹 버전

PLAYVAULT 첫 화면 카드 → `games/family-chess-premium/play/`. 같은 소스를 `npm run build:web`으로 빌드해 커밋한다. PC·태블릿 가로 화면 기준(가족 결정: 휴대폰은 너무 작음). 웹 기록은 브라우저별 저장.

## 4. 가족이 정한 원칙

- **"너무 화려하지 않게"** (엄마) — 모든 스킨·연출의 기준. 빛·금박·과한 광택 없음.
- 작은 화면에서 읽히는 것이 세부 장식보다 우선(중세·노블 제외 이유).
- 앱 ID `com.playvault.familychess`는 바꾸지 않는다(기록 유지).

## 6. 가능성으로 남겨 둔 것 (착수 안 함)

### 판매 가능성 (2026-11-04 검토, 결정 보류)

- 이름: "Chessmaster"는 Ubisoft 상표 → 판매 시 변경 필요. 후보로 "체스 아카데미"가 거론됨(같은 이름의 앱이 이미 있을 수 있어 상표·스토어 검색 필요).
- Stockfish(GPL-3.0): 판매는 가능하나 앱 전체 소스를 GPL로 공개해야 함. 비공개 판매라면 자체 엔진으로 교체 필요.
- 문제(Lichess CC0)·글꼴(OFL)·chess.js(BSD)·자체 그림·효과음: 판매에 문제 없음.
- Google Play: 비공개 업로드 키(저장소의 공개 키 사용 금지), 가족 정책, 개인정보처리방침. Steam: PC 포장 추가 작업.
- 차별점이 관건: 일반 학습 앱과 달리 "부모·아이가 한 기기에서 함께 두고 함께 배우는" 구성, 완전 오프라인·광고 없음, 한국어 강의가 후보.
