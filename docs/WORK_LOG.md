# 누적 개발 이력 (WORK_LOG)

> 규칙: [`AGENTS.md`](../AGENTS.md) §2-3, §8

## 기록 규칙

1. 작업이 끝날 때마다 **이 파일의 맨 아래에 새 항목을 추가**합니다. 시간순(오래된 것 → 최신)으로 쌓습니다.
2. 기존 항목은 **삭제하거나 덮어쓰지 않습니다.** 오류가 있으면 새 항목에 "정정"으로 남기고 대상 항목 번호를 적습니다.
3. 항목 번호는 `WL-0001`부터 1씩 증가합니다.
4. 확인하지 못한 내용은 **미확인**, 실행하지 못한 테스트는 **실행하지 못함(이유)** 으로 적습니다.
5. 자동 테스트 결과와 사람의 플레이·청취 평가를 구분합니다.
6. 커밋 해시는 짧은 형식(7자)으로, PR은 번호와 주소로 적습니다. 병합 전이면 브랜치 이름을 적습니다.
7. 이 파일 도입(2026-10-31) 이전의 이력은 아래 "도입 이전 이력" 표에 Git 기록만으로 요약했습니다. 그 시기의 테스트 결과·요청 배경은 커밋에 없으면 **미확인**입니다.
